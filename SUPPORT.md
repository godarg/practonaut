# Getting help

- **Questions and ideas:** open a GitHub issue (or a discussion, if enabled for the repository).
- **Bugs:** use the bug report template; include `npx practonaut --version`, your OS, Node version
  and the command you ran. `npx practonaut doctor` output helps.
- **Security issues:** follow [SECURITY.md](SECURITY.md), never a public issue.

Start with [docs/getting-started.md](docs/getting-started.md) and `practonaut <command> --help`.
Practonaut is maintained by a very small team without a support commitment; we answer as time
allows.

Platforms: macOS, Linux and Windows with Node.js ≥ 22.18. Development happens on macOS; Linux and
Windows are covered by CI (see [docs/testing.md](docs/testing.md)).
