# PADR-0009 — License, npm package and publication path

Status: accepted · Date: 2026-10-03 · License and copyright line confirmed by the maintainer on
2026-10-03 (copyright line as in `NOTICE`).

## Context
The project is meant to become a free open-source project with a public repository and an npm
package. Nothing is published yet. The name is chosen internally; trademark clearance, domain
ownership and account names are not confirmed (`measured` 2026-10-03 15:15 UTC: npm package
`practonaut` unpublished (404), `github.com/practonaut` 404, `github.com/OWNER/practonaut`
404; npm org/user pages returned 403 to automated requests → `UNKNOWN`).

## Options (license)
MIT (short, used by the maintainer's other project), Apache-2.0 (explicit patent grant and
contribution terms), MPL-2.0 (file-level copyleft).

## Decision
- **Code license: Apache-2.0** with a `NOTICE` file. Reason: an extensible platform with
  adapters and community contributions benefits from the explicit patent grant and the
  contribution clause; no contributor license agreement is needed. Contributions carry a
  Developer Certificate of Origin sign-off.
- **Content licenses are per asset.** World packages and recordings declare their own licenses
  (for example CC0-1.0 or CC-BY-4.0); examples in this repository are self-made and CC0-1.0.
- **npm:** one package, `practonaut`, providing the CLI, the session host, the MCP server and
  the player assets. `"private": true` until the release step flips it. Files allowlist:
  `dist/`, `schemas/`, `README.md`, `LICENSE`, `NOTICE`, `CHANGELOG.md`. No install scripts.
- **Publication** happens only from GitHub Actions with npm trusted publishing (OIDC, no
  long-lived token) and provenance, from a protected tag, on npm ≥ 11.5.1 in the release job
  (the local machine has npm 10.9.8, `measured`). Supply-chain target: SLSA build provenance as
  generated by that path; no higher SLSA level is claimed.
- **Repository:** GitHub under the maintainer's account, public only after a content and rights
  audit. `main` is protected; changes land through pull requests with required checks. The
  first push of a public repository is a **snapshot** of the audited tree without a private review record
  (machine-bound prompts and review records containing local paths), created as a fresh
  initial commit; the private development history stays local. This is not a history rewrite
  of a shared repository.
- Steps that need the maintainer in person (account, 2FA, npm trusted-publisher setup,
  repository creation, visibility switch, domain and trademark decisions) are listed in
  `docs/release.md`. No agent performs them.

## Consequences
Release engineering is prepared and testable locally (`npm run test:pack`) without publishing.
Using the name publicly remains a maintainer decision under open trademark risk.

## Re-assessment triggers
Maintainer prefers another license; a trademark conflict; npm or GitHub policy changes for
trusted publishing.
